ℹ️ Sobre a PoC

O GuiaFoco é uma prova de conceito de um sistema de intervenção adaptativa para alfabetização infantil. Nesta versão, os dados são gravados no banco MySQL por meio da API em C# (ASP.NET Core). A futura integração com IA poderá aprofundar a análise do desempenho.
